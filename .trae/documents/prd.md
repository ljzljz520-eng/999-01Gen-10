## 1. 产品概述

实验试剂批号查询系统，用于实验室试剂信息管理与查询，帮助实验人员快速获取试剂详细信息，确保实验安全与质量可控。系统支持试剂信息追溯、质检报告版本管理、投诉预警等功能。

- 主要用途：实验室试剂信息管理与查询
- 解决问题：试剂信息分散、质量追溯困难、投诉预警不及时
- 目标用户：实验人员、实验室管理员
- 产品价值：提升实验室安全管理水平，确保实验数据可靠性

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 实验人员 | 系统分配账号 | 试剂批号查询、查看试剂详情、查看安全说明 |
| 管理员 | 系统分配账号 | 试剂信息管理、质检报告上传、投诉记录管理、报告版本追溯 |

### 2.2 功能模块

1. **登录页**：用户身份验证、角色切换
2. **试剂查询页**：批号搜索、试剂详情展示、投诉预警提醒
3. **管理员控制台**：试剂信息管理、质检报告上传、版本历史查看、投诉记录管理

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 登录页 | 登录模块 | 账号密码登录、角色选择（实验人员/管理员） |
| 试剂查询页 | 搜索模块 | 输入试剂批号进行搜索、搜索历史记录 |
| 试剂查询页 | 试剂详情卡片 | 展示纯度、到期日、储存条件、安全说明 |
| 试剂查询页 | 开封记录模块 | 开封时间、操作人员、开封状态 |
| 试剂查询页 | 投诉预警模块 | 同批次投诉时醒目红色警告、停止使用提示 |
| 管理员控制台 | 试剂管理模块 | 试剂信息新增、编辑、删除 |
| 管理员控制台 | 报告上传模块 | 质检报告上传、版本号自动生成 |
| 管理员控制台 | 版本追溯模块 | 报告版本历史、版本对比、版本下载 |
| 管理员控制台 | 投诉管理模块 | 投诉记录新增、状态更新 |

## 3. 核心流程

实验人员查询试剂流程：
用户登录系统 → 选择实验人员角色 → 进入查询页面 → 输入试剂批号 → 系统展示试剂详情 → 检查同批次投诉 → 如有投诉显示红色警告 → 实验人员查看详细信息

管理员上传质检报告流程：
管理员登录 → 选择管理员角色 → 进入控制台 → 选择对应试剂 → 上传质检报告 → 系统自动生成版本号 → 保存版本历史可追溯

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：专业科研蓝 (#165DFF)，体现严谨专业
- 辅助色：警示红 (#F53F3F) 用于投诉警告，成功绿 (#00B42A) 用于正常状态
- 按钮风格：圆角矩形按钮，主按钮蓝色填充，次按钮灰色边框
- 字体：标题使用粗体无衬线字体，正文使用清晰易读的无衬线字体
- 布局风格：卡片式布局，信息分组清晰
- 图标风格：线性图标，简洁专业

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|----------|
| 登录页 | 登录卡片 | 居中卡片布局，蓝色渐变背景，输入框带图标，登录按钮 |
| 试剂查询页 | 搜索栏 | 顶部搜索框，搜索历史快捷按钮 |
| 试剂查询页 | 详情卡片 | 网格化信息卡片，状态标签，到期日倒计时显示 |
| 试剂查询页 | 警告横幅 | 红色渐变背景，闪烁动画效果，醒目警告图标 |
| 管理员控制台 | 侧边导航 | 左侧导航菜单，当前选中高亮 |
| 管理员控制台 | 数据表格 | 斑马纹表格，操作列按钮 |
| 管理员控制台 | 上传区域 | 拖拽上传区域，版本号自动填充 |
| 管理员控制台 | 版本时间线 | 垂直时间线，版本节点，下载按钮 |

### 4.3 响应式

桌面端采用1200px以上布局，平板端自适应，移动端单列布局，触摸优化。

### 4.4 交互细节

- 搜索结果加载动画
- 卡片悬停阴影效果
- 警告横幅呼吸动画
- 版本时间线渐入动画
- 表单输入框聚焦动效
